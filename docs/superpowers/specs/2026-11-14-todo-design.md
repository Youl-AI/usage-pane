# 사용량 패널 아래 할 일 목록 — 설계

2026-11-14, 사용자와 대화로 정함.

> **2026-11-20 변경 (0.7.0):** 사용자 요청으로 "Claude가 자동으로 적기"를 뺐다. `todo_add` 도구를 더 등록하지 않고, 항목은 입력칸으로만 들어간다.
> 새 세션 첫머리에 남은 할 일을 넘기는 것은 그대로 두되, Claude는 읽기만 한다고 적었다.
> 0.6 이하에서 Claude가 넣은 항목은 지우지 않고 "Claude가 적었던 것" 묶음에 남긴다. 그런 항목이 없으면 묶음 제목 없이 한 목록으로 보인다.
> 아래 본문은 처음 설계 기록으로 남겨 둔다.

## 목적

작업하면서 다음에 할 일을 잊지 않도록, 사용량 패널 안 아래쪽에 프로젝트(작업 폴더)별 할 일 목록을 둔다.

## 사용자가 정한 것

- 직접 적기 + Claude가 자동으로 적기를 섞는다(3번 방식).
- Claude가 자동으로 적는 조건: **대화에 할 일 목록이 실제로 나올 때만.** 예: Claude 답의 "남은 것"·"다음에 할 일" 목록, 사용자가 나열한 할 일. "나중에 하자" 같은 한마디는 넣지 않는다.
- 별도 패널이 아니라 **사용량 패널 아래 빈 공간**에 넣는다(앱이 패널을 탭으로 묶어 위아래로 쌓을 수 없어서).
- 디자인은 사용량과 같은 느낌. 시안 C: **누가 적었나로 묶기**(Claude가 적은 것 / 내가 적은 것), 적은 날짜 표시.
- **완료한 항목은 줄을 긋는다.**

## 검토한 방식

| 방식 | 판단 |
|---|---|
| 직접 적기만 | 예측 가능하지만 결국 안 쓰게 되기 쉬움 |
| Claude가 알아서만 | 모르는 사이 목록이 불어남 |
| 섞기, 자동은 목록이 나올 때만 (선택) | 사용자가 고름 |
| 별도 mod·별도 패널 | 패널이 탭으로 묶여 사용량과 같이 못 봄 → 기존 mod에 넣음 |

## Claude의 판단 (사용자가 바꿀 수 있음)

- 완료 항목은 각 묶음 아래쪽에 줄 긋고 흐리게 남긴다. "완료 항목 지우기" 버튼으로 한꺼번에 지운다.
- 저장: `$.store`에 작업 폴더 경로별로(`todos:<cwd>`). 이 PC에만 남는다. 항목 최대 200개.
- 같은 내용(앞뒤 공백·대소문자 무시)이 이미 있으면 다시 넣지 않는다.
- Claude용 도구 `todo_add({ items: string[] })`. 설명에 "할 일 목록이 나왔을 때만" 조건을 적는다. 호출 보장은 없다.
- 새 세션 시작 때 남은 할 일을 시스템 프롬프트 끝 한 단락(`usage-pane:todos`)으로 넘긴다. 대화 중에는 바꾸지 않는다(프롬프트 캐시 규칙).
- 할 일 영역은 앱 기본 요소(입력칸, 버튼, 글자)로 그린다. 누르고 입력해야 해서 SVG로는 못 그린다. 출처 색은 Claude=슬레이트 블루, 나=세이지(라이트·다크 양쪽에서 읽히는 중간 밝기).
- 항목을 누르면 완료/미완료가 바뀐다. 항목 옆 `×`로 하나만 지운다.

## 하지 않는 것

기기 간 동기화, 마감일·우선순위, 할 일 편집(지우고 다시 쓰면 됨).
